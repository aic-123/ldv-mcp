# 它现在能做什么

> 2026-10-24 ｜ ldv-mcp 0.1.0（内核 v0.1.38）
> 下面的输出**逐字来自实跑**，不是示意。

## 一句话

**真人像平时一样用 agent。插件只提供两样东西：对 agent 的主体性，和一棵私人方向树。**

⇒ 真人对插件**零动作**：没有配置、没有选预设、没有「先建库再说」。
agent 有四件工具，对应它的四种动作；原先的「提议透镜 → 冻结 → 查 → 看状态」
透镜**首次使用即自动冻结**（原先的 propose/freeze 两件动作已沉成内部机制）。

---

## 三个场景（实跑输出）

### 场景 A｜真人只说一句话

```
$ orient（内置 36 项，会话开始）
  → 语料 内置语料（ldv/corpus）｜36 项｜24 个可用键｜透镜 frozen=None
  → 前 6 个键：['aliases', 'cues', 'evidence_status', 'evidence_status=有争议',
               'evidence_status=未验证', 'filled_by']

$ ask require=["type=概念"]
  → 8 项 / 2 支｜ordered_by=default
  → 支序：['D13', 'D14']
  → 出处摘要：{'模型(DeepSeek-V4.1-Flash)': 8}
```

`orient` 就是「**我记得**」：词汇表先给 agent 看（查询只能用这些键）。
答案带出处——这 8 条全是模型填的，因为内置语料的 `filled_by` 就这么写的。

### 场景 B｜私人语料：一步冻结 → 钻 → 写记忆 → 再 orient

```
$ ask（带 lens + rationale —— 一步，没有 propose/freeze 两个动作）
  → 透镜 {'id': 'a64fb0520c86', 'generated_by': 'agent',
          'corpus_fingerprint': '36:f2c8a76b5b719a73'}
  → 用的方向函数：keyset

$ drill D13（agent 代钻，actor 默认 agent）
  → recorded=True｜已记录（下钻 = 有用）；这批还剩 1 支待看

$ remember（往自己的私人语料写一条）
  → written=True｜filled_by=agent

$ orient（私人语料）
  → 项数 37｜使用记录 1 条｜演员分解 1/1
  → 透镜 stale=True（语料多了我写的那条 ⇒ 指纹不符，该重提一个）
  → 最近动作 5 条，第一个是 orient
```

四件事一次看完：**agent 自己选透镜（带理由）并当场生效**；代钻算有用但演员可分解；
`remember` 是主体性的落点——agent 有地方写自己的记忆，**只追加不覆写**；
写完语料变了，`orient` 立刻报 `stale`（材料一变，上一份认识作废）。

### 场景 C｜问一个语料里没有的维度

```
$ ask require=["作者国籍=中国"]
  → ok=False｜out_of_structure=True
  → 这些键不在词汇表里 —— 可能是拼错了；若确实没有这个维度，
    那是「超出结构」，请人介入，本层不猜
  → 建议：{'作者国籍=中国': []}
```

**它不猜。** 而且把「拼错了」和「真没这个维度」分开报（建议为空 = 没有相近键）。

## 八件工具（四件动作 + 四件能力）

| 工具 | 类别 | agent 用它做什么 |
|---|---|---|
| `orient` | 动作 | 「我记得」—— 私人语料 / 透镜（理由+指纹+是否过期）/ 使用记录 / 最近动作 / **词汇表与取值分布** |
| `ask` | 动作 | 翻译后的查询。内部：键校验 → 透镜（无则带 `lens` 自动冻）→ 支序原样 → 出处摘要 |
| `remember` | 动作 | 往自己的私人语料写一个节点（只追加不覆写，`filled_by` 照记） |
| `drill` | 动作 | 下钻 = 有用。agent 代钻与人的同权，`actor` 默认 agent |
| `derive` | 能力 | **派生维度** —— 词汇表没有的轴自己建（带理由与「从哪来」，删 sidecar 即回退） |
| `undo` | 能力 | **反事实** —— 删掉一个项看什么会变，然后原样恢复 |
| `next` | 能力 | **反思** —— 后果三档（必须/可延后/可忽略） |

⚠️ **打包成插件只舍弃自由度，不牺牲能力**：哪件暴露、哪件故意不给、哪件是风险，逐条记在 [`能力对账.md`](能力对账.md)。

## 能力清单（现在就能用）

| # | 能力 | 靠什么 |
|---|---|---|
| 1 | **零配置起跑** —— 真人只说一句话，其余 agent 自己来 | 四件工具，无真人步骤 |
| 2 | **词汇表先行** —— 查询前先知道能问什么，**以及语料的类型体系** | `orient` 的 `keys` + `value_counts`（哪个键有哪几个取值、各多少节点）；键校验在入口**之前** |
| 3 | **结构化查询** —— 「同时满足 A、排除 B」⇒ 树上若干支 | `ask`；支序**原样**返回 |
| 4 | **下钻即反馈** —— 钻哪支，哪支以后先摆出来 | `drill` → 使用记录 → 倾向（只改次序，**答案集合逐字不变**） |
| 5 | **agent 自选透镜** —— 带理由，当场生效 | `ask` 带 `lens`；**首次使用即自动冻结** |
| 6 | **语料变则认识作废** —— 指纹不符就报 stale | `orient` 的 `lens.stale` |
| 7 | **答案带出处** —— 语料 / 模型填 / 已验证三类分开数 | `ask` 的 `provenance` |
| 8 | **agent 有地方记忆** —— 写自己的私人节点，不覆写 | `remember` |
| 9 | **操作全留痕** —— 每次调用一行，只追加 | `store/log/mcp-calls.jsonl` |
| 10 | **演员可分解** —— 多少记录来自 agent 声明的下钻 | `orient` 的 `actor_split` |
| 11 | **造维度** —— 词汇表没有的轴，agent 自己建（带理由与出处） | `derive`；不写回材料，删 sidecar 即回退 |
| 12 | **反事实** —— 「删了这个会怎样」，问完自动恢复 | `undo`；指纹逐字比对过才报成功 |
| 13 | **反思** —— 此刻该干什么（后果三档，不是分数） | `next` |
| 14 | **读内容** —— 标题与正文，截断必报 | `ask` 的 `with_body` 选项（读内容是查询的参数，不是新工具） |

## 它现在**不能**做什么（诚实清单）

| 不能 | 为什么 |
|---|---|
| **不排序、不推荐** | 支序原样中转；「最相关的是……」这种话它不说 —— 排序即推荐，是红线 |
| **不主动找你** | 没有「你可能需要看这个」。它只回答你问的 |
| **不懂语义** | 「A 意味着 B」不做。它做结构：包含、可达、路径、反事实 |
| **不接不可信存档** | 内核的持久化格式仍是可信输入假设；别把陌生存档喂给它 |
| **语料要存在盘上** | 它不爬网、不导数据。语料 = 一个目录的 md 文件 |
| **没做规模验证** | 内置 36 项与复制它的私人语料上全绿；3907 项级别**没在本产品里跑过**（内核跑过） |

## 怎么自己验

```bash
python smoke_test.py        # S1–S37：真起一个 MCP 会话，跑完八件工具
```

十七条里最要紧的七条：未知键**必须被拒**、工具面**必须只有四件**、
支序必须与内核**逐字相同**、`provenance` 之和必须等于 `n_answer`、
`remember` 同 id **必须不覆写**且之后透镜**必须报 stale**。
它们判的是「约束是机制」——不是「agent 今天听话」。

## 已知的边界（不是缺陷，是形状）

- **分辨率随规模退化**：log 最大叶 对 log|U| 的斜率 ≈ 1.54 —— 语料越大叶子越粗。
- **倾向带演员口味**：agent 代钻算有用（定的），所以次序会带上 agent 的翻译偏好。
  兜底是 `actor_split` 可分解 + 日志可接管，不是「不算」。
- **reach 上互相可达的项会被劈开**（`id` 是 tie-break）—— 选 reach 时它的说明里写着。
- **`remember` 会让透镜过期**：这是**该有的行为**（材料变了，认识作废），
  不是 bug；重提一个透镜是一次 `ask` 的事。
