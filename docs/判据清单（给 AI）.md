# 判据清单（给 AI 读）

> 2026-10-25｜配套：repo `v0.1.42` / ldv-mcp `b3cec18`
> 这不是论文，是**操作手册**。你（agent）挂在这个外挂上，需要知道三件事：
> **能依赖什么、怎么自己验、看到红怎么办。**

---

## 0 怎么用这份清单（三条）

1. **你说出的话如果依赖某个承诺，先查它在不在 §1**。表里没有的 = **没有保证**，
   别用「系统保证」的口气说它。
2. **看到「红」不要解释成「偶发」**。每一条红都有「红了意味着」那一列 ——
   按那一列判断是致命、降级，还是只是记录。
3. **§5 是红线**。那几条不是「注意」，是「一旦做了，这套东西就不成立了」。

## 1 承诺（你能依赖什么）

每条都是一个可判的断言，`repo/docs/形式化断言集.md` 有陈述/前提/证明/最小反例。

| # | 承诺 | 守它的判据 | 红了意味着 | 你该怎么办 |
|---|---|---|---|---|
| **§S1** | **不产内容**：输出里每个字符串都能指回材料 | repo `test_no_unsourced_strings`（§S1 合成对照） | 系统自己编了一句话 | 把那句当**不可信**，要求它指回材料；不要复述它 |
| **§S2** | **答案是位置**：无命题、无跨项标量 | `[保证]` 的禁词检查（`score/weight/priority`） | 出现了打分/排序 | 立刻停下：这套东西一旦有分数就是推荐器，不是它 |
| **§S3** | **反思显性**：每条请求带证据（信号/链/阈值/涉及项/已试过） | `[保证]` 字段齐 + 项集复算 | 请求没带证据 | 不接受「系统建议加这个维度」这种无证据的说法 |
| **§S4** | **重构显性**：每次变更留账（生效/未生效/改名）+ 可回退 | `[保证]` 账可查 + 回退实测 | 改了但查不到账 | 要求它先说「改了什么、怎么退」 |
| **§S5** | **自我标签一致**：`我=是` 外生（人写）、可指认、可回退 | `[自我] ⑴⑵` | `我=是` 的项指不回真实文件 | 那个「自我」是编的，别引用 |
| **§S6** | **失配修复收敛**：改结构能让失配消失，且不弄坏结构 | MCP `S39a–e`（含反向对照） | 改了结构但需求仍失配 | 说明「改错了维度」——不是「加得不够」，是**加的不是要的那个** |
| **§S7** | **记忆处置是降权不是删除**：低于阈值不参与使用，但**依旧留在存储里**；忽略作用在**支**上，不在项上 | repo `[否定] ①–⑦`（含「明确问到不跳」的守卫与反向对照） | 某个支被跳过，但**项还在**（这是设计，不是数据丢了）；或者反过来：项级 `verdict` 改了候选集 | ①**别把「跳过」当「删了」** —— 想让它回来，把 `reject_below` 去掉或显式 `require` 它的 `must`；②项级标记**只标记**，判断权在你；③阈值是**外生**的，系统不会自己定 |

⚠️ **§S1 / §S2 / §S5 / §S7 只判到「半」**（契约可读、判据只守形状；S7 的「阈值该定多少」是外生约定）——
引用它们时说「按契约」，不要说「已验证」。

## 2 结构不变量（树本身的保证）

`repo` 的 `B1–B20`（20 条**反向对照**：每条都是「坏输入红、好输入绿、两者不同」）
+ `§K1–K9` / `§A1–A8` / `§D1–D8` 的断言。归纳成你能用的五句：

| 你依赖的事 | 依据 | 怎么自己验 |
|---|---|---|
| **每一支的答案 = 它成员的精确集合**（不重不漏） | `§K1` 严格派生 + `§I2` 覆盖 | `ask` 的 `n_answer` 与 `answer_ids` 对得上；`nodes` 各支成员互不相交 |
| **树是良基的、不会无限深** | `§K5` 良基秩 | `rank` 有上界；`_spread` 有 64 层防爆栈 |

| **空方向是合法的**（不是漏） | `§K2` 判空 ⟺ 同答案 | `unsplittable` 记着「试过分不开」；别把「判空」当「漏」 |
| **外生项不许被使用记录驱动** | `§K9` / `§D1` | `selfopt.optimize` 只动 `expand_priority.*` 与 `penalty_scale`；动了别的就是红 |

## 3 产品能力（MCP 的 S1–S46）

按你能做的事分组。**每条都真起 MCP 会话跑过**，不是设计意图。

### 3.1 查（`ask` / `orient` / `next`）

### 3.2 记（`remember` / `remember_answer`）

| 编号 | 保证 |
|---|---|
| `S14` | `remember` **只追加不覆写**（覆写 = 改写记忆） |
| **`S43a–d`** | **变更回执**（`orient.changes`）：本会话新写了哪些 id / 造了哪些维度 / 编译了哪些答案 / 降权了哪些支。**只收写，读操作一条都不进**（否则它就是 `recent_calls` 换了个名字）。不带 `session` ⇒ 汇总全部，但 `scope` **明说「这不是本次」** |
| **`S44a–c`** | **派生维度的元数据读得出来**：`orient.derived_meta` 与 `ask.derived_provenance` 原样透传 `what` / `why` / `derived_from` / `generated_by`。看 `derived_from`：写「原材料」的可当材料，写「模型推断」的只能当线索 |
| **`S45a/b`** | **类型错要报成类型错**：`require` / `forbid` 传裸字符串 ⇒ 报「要传列表」（不是「键不在词汇表」—— 那是误诊）。反向对照：传列表不许误伤 |
| **`S46a–d`** | **「报告不知道」是一条正式出口**：`remember_answer(unknown=true, why=…)` 把弃答记成 `type=未答` 的结论 —— 可查（`type=未答`）、可复核（`why` 必填）、可纠正（同键再答翻回来）。命中时单独报 `unknown: true`，**不会把「上次判定答不出」当成答案**。反向对照：不给 `why` ⇒ 拒（那是「哑」不是「弃答」） |

## 5 红线（做了就不成立）

| 别做 | 为什么 |
|---|---|
| **把「没有」说成「没有内容」** | 系统能区分「格子空」与「没这个维度」，你也必须分开说 |
| **替人判错**（`verdict=wrong` 且 `actor=agent`） | 判错只能外部授予；你会把自己读不懂的标成错的 |
| **自己发明阈值**（`reject_below`、维度、口径） | 阈值必须外生；自己发明 = 系统当裁判 |
| **把缓存当记忆** | 缓存会过期、会作废；`我=是` 的记录才是记忆 |
| **要求系统打分/排序** | 一旦有分数，它就是推荐器，不是它了 |
| **引用表里没有的「保证」** | 没判据 = 没保证。`§1` 的六条是全部 |

## 6 红了怎么办（分级）

| 级别 | 症状 | 处置 |
|---|---|---|
| **致命** | `§S1`（编内容）/ `§S2`（出现分数）/ `B` 系列红 | **停**。不要在红的状态上继续结论；报给用户 |
| **降级** | `S39` 闭环红 / `[否定]` 差额对不上 | 能用但要**明说**「这次修复没验证」 |
| **记录** | 探针读数偏移（成本/规模） | 照常用，但把读数报出来，别默认「还是那个数」 |
| **跳过 ≠ 红** | 语料性质导致（如 `B17` 在 DAG 语料上跳过） | **不要修它**。跳过是「这份语料上没内容」，不是「判不了」 |

## 7 协议合规（M1–M8，官方 SDK 验过）

这一节不是「承诺」，是**你能连得上**的证据 —— 用官方 MCP Python SDK 真握手跑出来的
（`probes/mcp_conformance.py`，留档 `probes/out/mcp_conformance.out.txt`）。

| 编号 | 保证 | 你该怎么用 |
|---|---|---|
| `M1` | 握手合规，**版本协商**（回你发来的那个） | 别假设协议版本；读 `protocolVersion` |
| `M2` | `tools/list` 8 个工具全部可解析 | 工具面是 **8 个**（四动作 + 四能力） |
| `M3` | 8 个 `inputSchema` 全部合法（`required ⊆ properties`） | 按 schema 传参，别凭记忆 |
| `M4` | `content[0].text` 是完整 JSON | 解析 text，别找 `structuredContent`（**故意不返回**） |
| `M5` | 未知工具 ⇒ JSON-RPC 错误（-32602） | 工具名拼错会报错，不会静默成功 |
| `M6` | 参数导致业务错 ⇒ `isError` + 说明 | 读 `isError`，别把错误当结果 |
| `M7` | 出错后**连接仍可用** | 不必重连 |

1. **协议版本必须协商**：写死回旧版本 ⇒ 新客户端直接断开（现象是「握手时 Connection closed」，
   而 server 自己没崩）。现在回客户端发来的版本。
2. **`structuredContent` 要配 `outputSchema`**：没配就返回，严格客户端会校验失败 ⇒ 已删。
