# 主体性判据：差异能表示「它有一个连续的自己」吗

> 2026-10-24 ｜ 探针 `probes/subjectivity.py`，读数逐字来自实跑

## 先把两件事分开

上一轮的「有插件 vs 没插件」实验（[`有插件和没插件的差距.md`](有插件和没插件的差距.md)）
测到的是：**答案能指回材料、不捏造、覆盖全**。

那些证明的是「**有依据**」—— 词典也有依据。**不叫主体性。**

主体性要测的是另一件事：

    它的行为被**自己过去做过的事**改变，且这个改变 **可归因**、**可回滚**。

## 五条判据（实跑读数）

### T1 连续性 —— 它自己做过一件事，同一问题的结果就变了

```
① 基线（它还没做过任何事）
   支序 ['D12', 'D16']｜ordered_by=default
② 它自己钻了最后一支 D16 ⇒ recorded=True
   同一问题再问：支序 ['D16', 'D12']｜ordered_by=usage
```

唯一变量是**它自己的动作**：同一个 store、同一个进程、同一个问题。
不是模型随机性 —— 模型随机性不会稳定地把「它刚钻过的那支」顶到第一位。

### T4 不是裁判 —— 次序变了，集合没变

```
2 项 / 2 支｜集合相同 True
```

⚠️ 这条是边界，不是补充：**它有自己的「视角」，没有自己的「结论」**。
主体性不等于裁判权 —— 一旦它能改答案集合，它就是推荐器了（红线）。

### T2 归因 —— 变化指得到「谁做的」

```
日志 drill 1 条｜actor_split 1/1
```

`store/log/mcp-calls.jsonl` 里有那条 drill，`orient` 的 `actor_split` 报得出
「1 条记录来自 agent 声明的下钻」。⇒ 这个「自己」不是模糊的连续性，是**可查的档案**。

### T3 独立于权重 —— 新进程仍在；删掉私人记忆即回滚

```
新进程仍 usage=True｜删 usage 后回默认=True（支序 ['D12', 'D16']）
```

**这一条是整组判据里最硬的**：它把「变化来自私人状态」与
「变化来自模型随机性 / 缓存 / 上下文」分开 —— 后三者**删不掉**，
而私人状态删掉就回滚。

### T5 反例 —— 无插件侧不是「做不到」，是「没有那个位置」

同一问题问两遍，无插件时不存在「钻过哪一支」这件事。
⇒ 差异不是量的（记得多/少），是**质的**：一个由上下文携带，一个由**自己的档案**改变。

## 长流程 + 大语料：放大到 1200 项、15 轮、10 条查询

短流程（36 项、1 个问题、1 次下钻）只够证明「机制成立」。用户要求更长的流程和更大的数据：

    语料  snap-hepth，**1200 项 / 19 个键**（比内置 36 项大 33 倍）
    流程  **15 轮**（ask + drill 交替）
    查询  8 条**单支**（type=1992…1999）+ 2 条**多支**（require 空 / source.kind=数据集）
    探针  `probes/subjectivity_long.py`

### 第一版实验的直接发现（这是本轮最重要的一条）

**只用了 8 条单支查询 ⇒ 15 轮之后 0/8 条次序变了。**

不是机制坏了 —— `entry.query` 里 `len(nodes) > 1` 才按倾向排序。
单支题的答案是**一整支**，没有「先看哪一支」这回事 ⇒ **历史结构上没有表现面**。

⇒ **主体性的可见性依赖查询形状**：
问得越具体（答案收窄到一支），历史越看不见；问得越宽（分成多支），越看得见。
一两个问题的实验看不见这一点 —— 那是被问题形状挑出来的巧合。

### 改成分两组之后（读数）

```
① 基线（还没做过任何事）
   多支 全部    ⇒ 1200 项 / 8 支｜default｜['D1','D3','D5','D7','D9','D11','D13','D14']
   多支 数据集  ⇒ 1200 项 / 8 支｜default｜同上

② 15 轮：单支/多支交替，各钻一支
   #04 多支 数据集 ⇒ 钻 D1（150 项）recorded=True
   #06 多支 全部   ⇒ 钻 D1（150 项）recorded=False   ← 同 (qfp,did) 去重
   …

③ 15 轮之后
   多支 全部   ｜default → usage｜['D1','D3','D5',…] → ['D1','D14','D13',…]
   多支 数据集 ｜default → usage｜同上
   单支 ×8     ｜default → default｜**0/8 变**（结构上不可能）
```

| 判据 | 读数 |
|---|---|
| **L1a** 多支查询次序变了 | 2/2（`ordered_by` default → usage，钻过的 D1 排第一） |
| **L1b** 单支查询次序**不可能**变 | 0/8 变；8 条全部 `n_branches=1` |
| **L2** 不是裁判 | **10 条查询**的 `answer_ids` / `n_answer` / `n_branches` 全同 |
| **L3** 独立于权重 | 新进程复现 ✓；**删掉 `usage/` 后 10 条全部回滚到基线** ✓ |
| **L4** 归因 | 日志 52 行 == 调用 52 次（orient 2 / ask 35 / drill 15）；15 次 drill **去重后 10 条记录**；倾向覆盖 5 个方向 |
| **L5** 写语料真的改答案 | `remember` 一条 `type=1999` ⇒ 150 → 151 项（材料变了就该变，与 L2 不矛盾） |

### 规模上多出来的两条认识

1. **去重是必须的**：15 次 drill 只落 10 条记录（同 `(qfp, did)` 只写一次）。
   如果叠加，钻同一个方向 5 次就等于把它捧成第一 —— 那是把「多看了一眼」当「更有用」。
2. **「集合不变」与「写语料改答案」不矛盾**：前者说的是**同一次查询**在历史变化前后
   集合不动；后者是**材料本身**变了。两件事分开测，别混着报。

## 结论：能表示，但只到这一层

**能表示**：可操作意义上的主体性 —— 有一个**连续的、可归因的、独立于权重的自己**，
且它会被自己的过去改变（T1–T3 同时成立，缺一条都不算）。

**证不了三件事**（说清楚，不糊）：

1. **不等于意识或意图**。这是一个结构性质，不是心灵哲学的主张。
   它没有自己的目标，也不会主动想要什么 —— 它的「自己」只体现在**次序**上（T4）。
2. **这个「自己」是可丢弃的**。载体是文件不是权重（这正是设计目标：记忆外化），
   所以删掉文件，这个自己就没了（T3 的反面）。**这是它与人的主体性的根本区别**，
   不是缺陷 —— 但别把它说成别的东西。
3. **它只到「视角」为止**。答案集合逐字不变，所以准确的说法是：
   **它有一个自己的看法顺序，没有自己的结论。**

## 复现

```bash
python probes/subjectivity.py       # T1–T5，逐条打读数
python probes/subjectivity_long.py  # L1a–L5，1200 项 / 15 轮（要 LDV_DATA）
```

「模型自己记住了」的说法，都过不了这一条 —— 那种记忆删不掉。
