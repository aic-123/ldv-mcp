# 预设一：keyset（键集切分）

**一句话**：按字段的组合切分 —— 两个项只要在某个字段上取值不同，就可能落在不同方向。

## 什么时候选它

- 语料的字段**天然多值**：类型、来源、状态、类别（论文的 `type=综述` / `source.kind=期刊`）
- 你想问的是「**同时满足**这几个条件的有什么」：`require: ["type=综述", "influence=≥100"]`
- 你希望切分结果**一句话能解释**：每个方向就是一组键的交集

## 什么时候别选它

- 语料是**图/网络**（引用、依赖、关注）—— 「从 X 出发走得到谁」这类问题它表达不了，换 `reach`
- 语料有**顺序/路径**结构（流程、调用链）—— 换 `sequence`

## 最小声明

```json
{
  "插件": "keyset",
  "参数": {"说明": "按字段交集切分；叶子 = 一组键同时成立的项"},
  "理由": "内置语料的字段天然多值，键集切分最直观、每个方向能一句话解释"
}
```

## 实测参考（内置 36 项语料）

方向 25 个｜最大等价类 7｜分支熵 0.55–0.91。**分辨率随规模退化**（log 最大叶 对 log|U| 的斜率 ≈ 1.54）—— 语料越大，叶子越粗，这是结构性质，不是 bug。
