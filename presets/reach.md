# 预设二：reach（可达切分）

**一句话**：按「从一组锚点出发，走得到吗」切分 —— 方向 = 一组锚点，成员 = 从这些锚点可达的项。

## 什么时候选它

- 语料是**有向图**：引用网络、依赖关系、影响传播
- 你想问的是「**受 X 影响的**有什么」「**够得着** Y 的有什么」—— 这是 keyset 表达不了的
- 你接受「假阳」：说「是」的方向里可能没有真命中的项（代价是性能，不是正确性 —— 内核 `B1` 专门查假阴）

## 什么时候别选它

- 语料**没有边**（纯字段表）—— 没有「可达」这回事
- 你需要**精确答案**且图很大 —— 粗方向会捞回很多项，靠查询时下钻收敛

```json
}
```

## 实测参考（内置 36 项语料）

方向 71 个｜`reach` 带距离缓存（键 = 锚点集）—— 缓存不改变数值语义，有判据钉住。
⚠️ 互相可达的项会被劈开（`id` 是认输的 tie-break）—— 这是已知形状，`B17` 在 reach 上只报不判。
