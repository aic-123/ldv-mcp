# 预设三：sequence（顺序切分）

**一句话**：按路径/次序的**形状**切分 —— 方向 = 一组模式，成员 = 路径能匹配上某个模式的项。

## 什么时候选它

- 语料有**序列结构**：流程、调用链、依赖路径、trie 形状的前缀
- 你想问的是「**走过同一条路**的有什么」
- 扇出自然大于 2（有序方向本来就是 k 叉，不要求二叉）

## 什么时候别选它

- 语料是**无序**的字段表 —— 换 `keyset`
- 你关心的是影响范围而不是路径 —— 换 `reach`

## 最小声明

```json
{
  "插件": "sequence",
  "参数": {"说明": "方向 = 路径模式组；成员 = 路径匹配某模式的项"},
  "理由": "语料里有流程/依赖链，切分该按走过的路径形状来"
}
```

## 实测参考（内置 36 项语料）

方向 16 个｜序列 36/176。
⚠️ **维护路径上批量插入与逐个插入不等价**（根因：`_tried` 记的「分不开」只对那次成员集成立）—— 这是已知代价，内核的未做清单里写着；本产品默认走批建路径（等价），不碰维护路径。
