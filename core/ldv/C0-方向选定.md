# C0 · 方向的选定

**这一步做什么**：按设计文档 §9，选**差异足够大**的方向，用来试**同一个内核**。
选得太像 ⇒ 都过只是都没碰到边界 ⇒ 验收给出假阳性（停止条件 **S5**）。

    §2 / §3  方向 A、B（第一轮，用于 C5 判定）
    §4       方向 C（第二轮，用于 C5b 复核）—— 前两个**都是无序的**，C 补上**有序**

---

## §1 语料

`rl-scaffold/nodes` 36 个节点，形状：YAML front-matter（`id / type / title / aliases /
cues / scope / source{ref,kind} / evidence_status / relations / filled_by / notes`）+ 正文。
节点间有 `relations` 指向，构成一张图。

---

## §2 两个方向

### 方向 A —— **键集包含**（`plugins/keyset.py`）

- 项的「键」= 该节点 front-matter 里出现的字段名 + 枚举字段的**取值**
  （`type=概念`、`evidence_status=未验证`、`source.kind=教材` …）
- 方向 = 一个**要求出现的键的子集** `K`
- 项 x 属于方向 d ⟺ `keys(x) ⊇ K`
- 合并 = **交**（要求变少 = 方向变粗）
- 代价 = **计数**（把 x 放进来要丢掉几条要求）
- 命中 = 结构包含检查，`O(1)`，只看节点自己

### 方向 B —— **锚点可达**（`plugins/reach.py`）

- 图 = `relations` 边
- 方向 = 一个**锚点集合** `S`
- 项 x 属于方向 d ⟺ 存在路径 `x →* s`（`s ∈ S`），含 `x ∈ S` 自身
- 合并 = **并**（锚点变多 = 方向变粗）
- 代价 = **距离**（x 到最近锚点走几步）
- 命中 = 可达性闭包，需要遍历整张图

---

## §3 差异轴（**这张表就是 C5 判定的前提**）

| 轴 | A 键集包含 | B 锚点可达 |
|---|---|---|
| 判定依据 | 节点**自身**字段 | 节点在图中的**位置** |
| 命中开销 | `O(1)` | 需要闭包/遍历 |
| 合并运算 | **交**（收缩要求） | **并**（扩张锚点） |
| 代价语义 | **计数** | **距离** |
| 「否」怎么来的 | **证明**出来的（两个包含关系） | **遍历**出来的（闭包为空） |
| 第三态从哪来 | 分辨率不够 | 分辨率不够 **+ 拒绝遍历** |
| 项的身份 | 与图无关 | **依赖整张图** |
| 世界在哪 | 无世界（自包含） | 需要图 ⇒ **插件闭包住世界** |
| 劈开依据 | 按枚举取值切 | 按图位置切 |

> **实测修正**：本表初稿写「A 的第三态来自『键缺失 ⇒ 结构性未知』」。
> 实测**不成立** —— 键要求是一个**健全的界**，不会对查询沉默：
> 它要么证明「否」（两个包含关系之一成立），要么说「是」。
> 所以 A 的第三态**只**来自分辨率。见 `C5-判定报告.md` §6 D6。

**为什么这算「差异足够大」**：上表九条轴里有七条不同，且其中两条
（**代价语义**、**世界在哪**）正好落在接口最容易押错的位置上 ——
§I3 只有一个 `代价 → 可比较的数`，它得同时容纳「计数」和「距离」；
§I1 的签名 `命中(方向, 查询)` 里**没有世界参数**，
所以 B 必须把图**闭包进插件实例**。

**如果这两个方向都能只写插件跑通，接口就算押对了**（C5）。

## §4 方向 C —— **序列前缀**（`plugins/sequence.py`，第二轮）

### 为什么非要有第三个

**A 和 B 的 payload 都是无序集合。** 把元素顺序打乱，方向一点不变。
⇒ 两个都过，可能只是**两个恰好相像**。第三个必须压它们压不到的位置。

### 它是什么

    seq(x)        = 从 x 出发的**确定性链**的 `type` 序列
                    （沿 relations，每步取 **id 最小**的未访问后继，最多 6 步）
    方向 payload  = 一组**前缀**（前缀语言 `frozenset[tuple]`）
    x 属于 d      ⟺ 存在 p ∈ payload 使 p 是 `seq(x)` 的前缀
    合并 = **并**     代价 = **前缀距离**（砍几个符号）     命中 = 前缀匹配

### 与前两个的差异

| 轴 | A | B | **C** |
|---|---|---|---|
| **有序吗** | 无序 | 无序 | **有序** ← 前两个压不到 |
| payload | (require, forbid) | 锚点集合 | **前缀语言** |
| 合并 | 交 | 并 | 并 |
| 代价 | 计数 | 图距离 | **前缀距离** |
| 量纲 | 整数 | 实数 | 整数 |
| 「否」的依据 | 证明 | 遍历 | **算覆盖集合** |
| 第三态 | 分辨率 | 分辨率 + 拒遍历 | 分辨率 |
| 世界 | 无 | 需要图 | **不需要**（`seq` 已把世界编进 payload） |
| 自然切分形状 | 二分够用 | 二分够用 | **trie（k 叉）** ← §I4 只给两个位置 |

**最后一行是这一轮的主要发现**：§I4 的「两个」是 B-tree 的遗产，
有序方向被迫把 k 个符号二分 ⇒ 切出 **43% 的空权威层**（B 是 0%）。
能装下，但要多花层数。详见 `C5b-第三方向复核.md` §2.1。

> ⚠️ 「43% 空权威层」是第 2 轮的实测数；那个度量后来改成
> **`§K2 判空` + 叶容量**（`§K2` 按字面实现之后，空壳不再物化）。
> 结论不变，只是读数换了：C 判空 8 次 / 叶容量 10，B 判空 0 次 / 叶容量 1。
> 见 `C7-流程跑通.md` §3.1.2。

### 语料侧的两个实测前提

    字段**顺序**   只有 1 种（front-matter 键序固定）⇒ 退化，不能当顺序轴
    确定性链      11 种，长度 0–5            ⇒ 用它当 `seq(x)`

**「确定性」是必须的**：只要有一个环节依赖遍历顺序，方向就不可复现（§8.2）。
每步取 id 最小的未访问后继 —— 这条规则本身也是 `B15` 能过的一个前提。
