组内奖励**全都相同**时，组内均值就等于每一条的奖励，分子为 0 → **优势为 0** → 这一组不产生梯度。

变量：这一组的奖励方差、batch 里这类组占的比例、梯度范数随 step 的变化

**DAPO 把它称为 Dynamic Sampling 要解决的问题**，并描述了后果链：
有效提示数持续减少 → 梯度方差增大 → 样本效率下降 → 训练信号被削弱。

**它给的对策**：动态采样——把这类组从 batch 里筛掉/补足，让进训练的那些组都有分辨力。

## 怎么确认

1. 把 batch **按 prompt 分组**，算每组的奖励标准差——**标准差为 0 的组就是白跑组**
2. 统计这些组占整个 batch 的**比例**（不是数量——比例才和梯度信号强弱直接相关）
3. 把 grad_norm 随 step 的曲线拉出来，和上面那个比例**对齐看**

**为什么判据是标准差，不是准确率**：组内归一化的分母就是组内奖励的离散度。
离散度为 0 → 分子为 0 → 优势为 0。
所以一个**准确率 50% 的组是有分辨力的**，一个**准确率 100% 的组没有**——
**看的是离散度，不是答对率。**

⚠️ **来源强度**：DAPO 原文写的是「准确率等于 1 的提示导致梯度递减」这个**现象**，
以及「有效提示数减少 → 梯度方差增大 → 样本效率下降」这条后果链。
**"按组算标准差"是本节点把它的机制读出来的，不是论文给的日志字段。**
