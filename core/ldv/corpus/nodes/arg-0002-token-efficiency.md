**论据的结构是"同性能下更省"**，而不是"同样预算下更强"。

论文的原话是：Dr. GRPO「**提升 token 效率，同时维持推理性能**」。

## 正文里能拿到的三类证据

**① 长度分布**（附录 F Table 5，DeepSeek 模型，平均响应长度）：

| 类别 | Base | R1-Zero |
|---|---|---|
| 正确回答 | 621.3 | 4965.4 |
| 错误回答 | 1038.9 | 8206.1 |

**② 训练成本**（§1）：极简配方跑 7B 基座，**8 块 A100 约 27 小时**。
→ 这是本产品里少见的、**明确的算力成本数字**。

**③ 准确率对比**（附录 B Table 4，AIME24 列）：

| 模型 | AIME24 | Avg |
|---|---|---|
| **Oat-Zero-7B（用 Dr. GRPO）** | **43.3** | **51.4** |
| R1-Distill-Qwen-7B @ 8k | 33.3 | 54.7 |
| SimpleRL-Zero-7B | 26.7 | 46.6 |
| PRIME-Zero-7B | 16.7 | 48.0 |
| OpenReasoner-Zero-7B @ 8k | 13.3 | 45.9 |

**读这张表要注意**：Oat-Zero-7B 的 **AIME24 最高（43.3）**，但 **Avg 不是最高**
（R1-Distill-Qwen-7B @ 8k 的 Avg 54.7 更高）。所以"新 SOTA"这个说法
**只在 AIME24 这一列上站得住**，论文自己也只举了 AIME24。

## 为什么这个论据对「偏差」有支撑力

如果偏差真的在**加长错误输出**，那浪费就发生在**错误答案**上——那里花的 token 没有任何收益。
于是"更省"本身就构成对"有偏差"的**间接支持**。

## 这个论据的强度边界

- 它依赖作者对「偏差」的界定，而那是他们自己的定义。
- **长度分布表证明了「错误回答更长」这个事实，但没证明「这是偏差造成的」**——
  论文自己给了替代解释（难问题需要更长推理，错误更可能来自难题），见 `judge-0003`。
- **它没有给出"加长了多少"的因果量化**。要拿到那个，需要的是
  「同一个基座、同一份数据、只切换优势公式」的对照实验——论文最接近的是
  附录 C 的消融（Fig 8/9），但那些数值**只在图里**。

→ 所以本论据能支撑「**这个改动不亏**」，**不能**支撑「**这个改动修掉了一个已知大小的浪费**」。
