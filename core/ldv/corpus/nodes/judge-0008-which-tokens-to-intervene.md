变量：token 级协方差的高分位与全体均值之比、被干预的 token 比例、熵曲线的走向

**先看一个分布**（原论文 §4.2 表 1，Qwen2.5-7B 训练第 1 步的协方差）：

| 分位 | 协方差均值 |
|---|---|
| Top 0.02% | 5.654 |
| Top 0.2% | 3.112 |
| Top 2% | 1.385 |
| Top 20% | 0.351 |
| Top 50% | 0.152 |
| **全部** | **0.003** |

**读法**：**万分之二**的 token，协方差是全体平均的**上千倍**。
所以熵崩塌不是「所有 token 一起推的」，是**极少数 token 在主导**。

→ 判据：如果你想干预熵，**要动的不是整个损失函数，是那一小撮 token**。

**论文给的两种做法**（都只碰高协方差 token，其余 token 照常更新）：

- **Clip-Cov**：随机挑一小撮高协方差 token，把它们的梯度**切断**（detach）
- **KL-Cov**：挑协方差最高的 top-k，对这些 token **加 KL 惩罚**

论文报告 **KL-Cov 的熵曲线比 Clip-Cov 更稳定**。

**为什么「加熵正则」这条路走不通**（论文 §4.1 实测）：
传统熵损失对系数**极度敏感**——
系数 0.0001 / 0.001 几乎无影响；0.01 直接**熵爆炸**；0.005 虽能稳住熵但**没有性能优势**。
参考模型的 KL 惩罚同样能稳熵，但**性能反而下降**。

**一个反直觉的对照**：这里干预的是 **10⁻⁴ 到 10⁻³ 比例**的 token，
却能**完全改变整条熵曲线**。论文把这称作熵控制的关键所在——
**少数关键 token 决定全局行为**。

**本节点不给推荐值**：干预比例、KL 系数这类东西随模型和框架变，
属于官方文档与实测的范畴，见 `ADAPT.md` §三。这里只记「往哪个方向动」。

## 怎么确认

1. 算 **token 级协方差**：中心化的 `logπ` 乘中心化的优势
2. 按**分位**看它的分布——**不是看均值**，是看高分位与全体均值之比
3. 比值到了**上千倍**的量级，就是"少数派在主导"（参照值见上面的表）

**第 1 步的量怎么来**：`logπ` 和优势都在你手里，中心化就是各自减均值。
这正是 `scope` 里那句"拿不到 token 级 logprob 或优势的实现不适用"的意思——
**这条判据不是看日志就能得到的，得自己在训练循环里算。**

⚠️ **第 2 步是定位方法，不是让你照抄 5.654 这个数**——
那个数是 Qwen2.5-7B 训练第 1 步的。你要的是**你自己那次训练的高分位/全体之比**。
